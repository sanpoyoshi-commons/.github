# Contributing

本プロジェクトは個人が開発・実験用に公開しているOSSです。

- **不具合報告・提案**: 各リポジトリの Issues へお願いします(日本語/英語可)。
- **Pull Request**: 歓迎しますが、個人運営のため確認・返信に時間がかかることがあります。
- **依存関係の更新**: リリース直後の依存更新はクールダウン期間(7〜14日)を置いて取り込む運用です。
- **セキュリティ脆弱性**: 公開 Issue ではなく、各リポジトリ Security タブの
  Private vulnerability reporting からご報告ください。
